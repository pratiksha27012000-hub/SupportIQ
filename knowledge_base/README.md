# StayEase SupportIQ — Synthetic Knowledge Base

This bundle contains 27 fictional documents created for the SupportIQ portfolio demonstration.

## Contents
- 8 guest policies (PDF)
- 6 hotel-partner policies (PDF)
- 8 support SOPs (DOCX)
- 5 knowledge articles (TXT)
- Metadata registry workbook/CSV in Metadata/

## Important
All StayEase content is synthetic. It is not an actual company's policy, legal guidance, or live operational instruction. Use it for ingestion, chunking, retrieval, citation, evaluation and demo workflows only.

Document version 1.0 is the synthetic content baseline. It does not imply real-world approval or operational adoption. Jurisdictional and legal compliance have not been assessed.

## Suggested ingestion order
1. Load the metadata registry.
2. Ingest policy documents.
3. Ingest SOPs.
4. Ingest knowledge articles.
5. Preserve document_id, version, audience, category, owner and tags as metadata.
